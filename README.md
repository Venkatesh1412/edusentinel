# EduSentinel

Early-warning dashboard that flags students who may be falling behind, explains **why**, and suggests a next step for the teacher.
Built for PRASUNEX INNOVATHON 2026, Round 3.

> Decision support only. A flag is a prompt for a conversation, never a verdict about a student.

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

The dashboard opens with a synthetic demo school (120 students, 4 classes, 10 weeks of data). To try the upload path,
choose **Upload CSV files** in the sidebar and use the four files in `data/`
(`students.csv`, `attendance.csv`, `marks.csv`, `homework.csv`). Regenerate them with `python generate_data.py`.

Run the tests with `pytest`.

## What it does

| Screen | Purpose |
|---|---|
| Class overview | Risk bands per class and an average-marks heatmap by class and subject |
| At-risk list | Ranked students with the reasons they were flagged and suggested actions; CSV download |
| Student drill-down | Risk score, reasons, next steps, and trend charts for attendance, marks and homework |
| Sidebar | Data source, class and risk-band filters, data-quality report, model information |

## How the risk score works

```
risk_score = 0.7 x rule_score + 0.3 x model_probability x 100        band: High >= 60, Medium >= 30, else Low
```

**Rule layer (explainable).** Points are added from five checks. Comparisons are strict, so exactly 75% attendance is *not* below 75%.

| Signal | Condition | Points |
|---|---|---|
| Attendance, last 4 weeks | below 75% / below 85% | 30 / 15 |
| Attendance drop vs previous 4 weeks | 10 points or more | 10 |
| Recent average mark (last 2 tests per subject) | below 40 / below 55 | 30 / 15 |
| Consecutive declining test rounds (each fall of 2+ marks) | 3 or more / exactly 2 | 15 / 7 |
| Homework completion vs class average, last 4 weeks | more than 25 / more than 12 points below | 15 / 7 |

**Model layer.** A scikit-learn logistic regression (median imputation, standard scaling) trained on a separate synthetic
cohort of 600 students. It adjusts the rule score; it never replaces it. When its estimate is 50% or more, it is shown
to the teacher as its own factor.

## Project layout

```
app.py                     Streamlit dashboard
generate_data.py           writes the demo CSVs to data/
edusentinel/
  data_gen.py              synthetic school generator (profiles, noise, ground truth for evaluation only)
  ingest.py                schema checks, row-level validation, data-quality report
  features.py              attendance windows, mark trend and streaks, homework gap
  scoring.py               rules, model training, blending, bands
  insights.py              factor -> suggested action mapping
  pipeline.py              validate -> features -> score -> actions
tests/                     pytest suite (ingest, features, scoring, pipeline, app smoke test)
```

## Testing

- Hand-computed feature tests on a tiny dataset
- Boundary tests on both sides of every threshold and band
- Bad-input tests (wrong columns, negative marks, `present` not 0/1, unknown IDs, duplicates)
- End-to-end checks on the demo school, including flagged-student recall and precision against ground truth
- A smoke test that runs `app.py` against a stand-in for Streamlit. It checks the app's logic and widget calls, **not** real rendering

## Limitations

- All data is synthetic. Accuracy on real school data is **not** validated; reported model metrics describe synthetic data only.
- The synthetic profiles were designed by the author, so results are optimistic compared with real life.
- No ERP integration (CSV import only), no login or role-based access, single school.
- Student-data privacy controls (consent, audit log, encryption) are planned, not built.
- The model can reflect bias present in historical data, so reasons are always shown beside the score.

## Third-party libraries

pandas, NumPy, scikit-learn, Streamlit, Matplotlib, pytest. Demo data is generated by `edusentinel/data_gen.py`; no external datasets are used.
